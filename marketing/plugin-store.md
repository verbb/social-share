Social Share gives Craft templates a consistent way to build social profile and sharing links. Use bundled icons and brand details, generate buttons quickly, and extend the provider catalogue when a project needs something specific.

Generate profile or share buttons for supported providers with their destination, icon, and familiar brand treatment. Helper options provide a quick result while templates can still control the surrounding markup and styling.

## Features

- **Share links:** Create provider-specific URLs for visitors to share the current page.
- **Profile buttons:** Link to a social account with recognisable icon treatment.
- **Bundled SVG icons:** Use provider artwork without carrying a separate icon folder between projects.
- **Brand colours:** Start from familiar provider colours and customise the presentation as needed.
- **Available counts:** Retrieve provider-supported follower or URL-share totals.
- **Custom providers:** Register another service behind the same template-facing API.
- **One provider API:** Work with each network through a common API for profile links, sharing URLs, and provider-supported follower or share counts. Register another provider or adjust an existing one without changing every template call.
